FAQ

Frequently asked questions

Does this extension collect my data?
No. All data is stored locally in your browser using chrome.storage.local. Nothing is sent to any server.
Will my text persist after closing the browser?
Yes. Your last input text, settings, and slices are saved locally and restored when you reopen the side panel.
What is "Slice" mode?
Slice mode splits text into a specified number of balanced parts, distributing words as evenly as possible across all chunks.
Which browsers are supported?
Text Splitter & Counter is built with Manifest V3 and uses the Side Panel API. It works on Chrome and Chromium-based browsers (Edge, Brave, etc.).
Can I load text from a file?
Yes. Click the "Load" button to import any .txt file directly into the text input area.
